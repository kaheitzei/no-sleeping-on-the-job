# no-sleeping-on-the-job

Keeps your Mac awake while [Claude Code](https://claude.com/claude-code) is actually working — including background work after a turn ends — and lets it sleep again as soon as Claude is idle. If the lid is closed, the Mac still sleeps.

macOS only (it relies on `caffeinate` and `pmset`).

## Install

Download [`install.sh`](install.sh) and run it:

```bash
curl -fsSL https://raw.githubusercontent.com/<you>/no-sleeping-on-the-job/main/install.sh -o install.sh
bash install.sh
```

That's it — one file, nothing else to fetch. It will:

1. Write `prevent-sleep.sh` and `allow-sleep.sh` to `~/.claude/hooks/` (executable).
2. Wire them into `~/.claude/settings.json` as `UserPromptSubmit`/`PreToolUse` (acquire) and `Stop`/`SessionEnd` (release) hooks — merging in, not overwriting, whatever is already in that file. A timestamped backup (`settings.json.bak-<epoch>`) is made first if the file exists.
3. Running it again is a no-op if the hooks are already wired up.

Start a new Claude Code session afterwards so it picks up the hooks.

## Uninstall

```bash
bash install.sh --uninstall
```

Removes exactly the hook entries this installer added (by matching on the script path) and deletes the two scripts. Everything else in `settings.json` is left alone.

## Verify it's working

While a Claude Code session is running:

```bash
pmset -g assertions | grep caffeinate
```

Turn on logging (`/tmp/claude_caffeinate/hooks.log`):

```bash
touch ~/.claude/hooks/.sleep-debug
```

Turn it back off:

```bash
rm ~/.claude/hooks/.sleep-debug
```

## How it works

- `prevent-sleep.sh` runs on `UserPromptSubmit` and `PreToolUse` and holds one `caffeinate -dimsu` process per Claude session (PID tracked in `/tmp/claude_caffeinate/<session_id>.pid`). It's a no-op fast path once the lock is held, refreshes it periodically, and sweeps stale PID files from crashed sessions.
- `allow-sleep.sh` runs on `Stop`. Instead of releasing immediately, it spawns a small watcher that polls `pmset -g assertions` for the Claude desktop app's own "keep awake while Claude works" assertion, and only releases the `caffeinate` lock once that assertion disappears (or after a 6-hour cap). On `SessionEnd` it releases right away.
- Everything is per-session, silent, and fails safe (every hook always exits `0`).

## Repo layout

- `hooks/prevent-sleep.sh`, `hooks/allow-sleep.sh` — the actual hook scripts (source of truth).
- `install.sh.template` + `build.sh` — `install.sh` is generated by embedding the two scripts above as base64; after editing anything in `hooks/`, run `./build.sh` to regenerate it. Don't hand-edit `install.sh`.
